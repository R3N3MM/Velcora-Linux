# PALISADE Linux Code of Conduct

## 1. Our Commitment

PALISADE Linux is an open-source community project focused on Cloud Administration.

We want to create a professional, welcoming and respectful environment where people can learn, contribute, share knowledge and work together.

We welcome contributors regardless of their experience level, technical background, nationality, age, disability or personal circumstances.

Everyone participating in the PALISADE community is expected to follow this Code of Conduct.

## 2. Expected Behaviour

All community members must:

- Treat other people with respect.
- Communicate professionally.
- Be constructive when providing feedback.
- Respect different technical opinions.
- Accept reasonable criticism.
- Give credit to other contributors.
- Respect project documentation and development procedures.
- Help new contributors understand the project.
- Report problems honestly.
- Respect the privacy and security of other community members.

Disagreements about technical decisions are normal. They must remain focused on the technical issue rather than becoming personal attacks.

## 3. Unacceptable Behaviour

The following behaviour is not acceptable:

- Harassment, bullying or intimidation.
- Discrimination or hateful language.
- Personal attacks or deliberate humiliation.
- Threats or encouragement of violence.
- Publishing private information without permission.
- Deliberately disrupting project discussions.
- Impersonating project maintainers.
- Submitting malicious code or intentionally harmful changes.
- Abusing repository permissions.
- Misusing community communication channels.
- Repeatedly ignoring reasonable moderation instructions.

## 4. Technical Discussions

Technical discussions should be based on evidence, testing and documented reasoning.

Community members may disagree with decisions, but they must do so respectfully.

Contributors should avoid:

- Insulting other developers.
- Presenting untested assumptions as confirmed facts.
- Deliberately misleading other contributors.
- Submitting changes that intentionally damage project functionality.

## 5. Project Security

Community members must respect PALISADE security procedures.

They must not:

- Publish private vulnerability reports without authorisation.
- Expose passwords, private keys or access tokens.
- Attempt to gain unauthorised access to project infrastructure.
- Introduce malicious software into project components.
- Abuse build systems or repository permissions.

Security vulnerabilities must be reported through the process described in SECURITY.md.

## 6. Reporting Violations

If you experience or witness unacceptable behaviour, report it to the project maintainers through the official project support channels.

Reports should include:

- A description of the incident.
- Relevant dates and times.
- The affected communication channel or project area.
- Supporting information where available.

Reports will be handled as confidentially as reasonably possible.

## 7. Enforcement

Project maintainers and authorised moderators are responsible for enforcing this Code of Conduct.

Depending on the seriousness of the behaviour, possible actions include:

1. A private warning.
2. A request to correct the behaviour.
3. Temporary restrictions on participation.
4. Removal of inappropriate content.
5. Temporary suspension from community activities.
6. Permanent removal from the community.
7. Revocation of repository or infrastructure access.

Serious security incidents or threats may require immediate action.

## 8. Fairness and Accountability

Enforcement decisions should be proportionate to the behaviour and supported by relevant information.

Where appropriate, affected individuals should be informed of the decision and the reason for it.

Maintainers must also follow this Code of Conduct.

Project authority does not give anyone permission to harass, intimidate or mistreat community members.

## 9. Scope

This Code of Conduct applies to:

- Official PALISADE GitHub repositories.
- GitHub Issues and Discussions.
- Pull requests.
- Official project communication channels.
- Community events organised by PALISADE.
- Other spaces where someone is officially representing PALISADE.

## 10. Final Statement

PALISADE Linux depends on cooperation, technical responsibility and mutual respect.

Every contributor has a responsibility to help maintain a professional and safe development environment.

By participating in the PALISADE community, contributors agree to follow this Code of Conduct.

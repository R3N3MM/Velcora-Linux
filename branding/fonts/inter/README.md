# Inter 4.1

UI and display typeface by Rasmus Andersson.
Upstream: https://github.com/rsms/inter — SIL Open Font License 1.1.

- `InterVariable.ttf`, `InterVariable-Italic.ttf` — preferred for
  desktop use (weights 100–900, optical sizing).
- `static/` — static Inter faces for software without variable font
  support. The Inter Display optical-size family is not vendored.
- `web/` — WOFF2 web fonts and the upstream `inter.css` with
  `@font-face` definitions for both Inter and InterVariable.

`LICENSE.txt` is the upstream licence and must stay with the files.

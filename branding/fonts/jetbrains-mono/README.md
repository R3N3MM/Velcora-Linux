# JetBrains Mono 2.304

Monospaced typeface by JetBrains.
Upstream: https://github.com/JetBrains/JetBrainsMono — SIL Open Font
License 1.1.

- `ttf/` — static TTFs, including the `JetBrainsMonoNL` (no ligatures)
  variants.
- `variable/` — variable TTFs (`JetBrainsMono[wght].ttf` and its
  italic).
- `webfonts/` — WOFF2 files for web use.

`OFL.txt` and `AUTHORS.txt` are the upstream licence and credits and
must stay with the files.
